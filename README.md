# segy-project
Projeto para Leitura, Visualização e Processamento de Dados Sismicos provenientes de arquivos SEG-Y


## Status do projeto

O projeto encontra-se na fase inicial de implementação.

A arquitetura, a estrutura de diretórios e as principais abstrações
foram definidas previamente. A implementação começou pelas entidades
e contratos centrais do domínio sísmico.
